## What is this repo?

This repo **is** my portfolio. GitHub Pages serves the files here as the website at **[mohra-makar.github.io/Mohraeil.github.io](https://mohra-makar.github.io/Mohraeil.github.io/)**.

I'm Mohraeil Asaad, a Computer Science student from Suez, Egypt, building a career in penetration testing. The site shows who I am, what I've done and how to reach me:

- **About and skills**: offensive security tools, programming languages and security topics
- **Experience**: web penetration testing, a SOC and GRC internship, and education work
- **Certifications**: Cisco, NTI, GDSC, CyberTalent and more
- **Projects**: my security write-ups and tools, linked straight to their GitHub repos
- **Contact**: email, LinkedIn, GitHub and my freelance profiles

## Features

- Single-page design in navy, pink and light blue, with an animated *Break. Learn. Secure.* intro
- Works on phones, tablets and desktops
- A sparkle cursor that follows the mouse (switched off for people who prefer reduced motion)
- One-click **Request a security check** email button
- Every project card links to its GitHub repo
- A private editor, so I can update my text, skills, certificates and projects without touching the code. Saving needs my own GitHub access, so visitors can't change the live site.

## How it works

| File | What it does |
|---|---|
| `index.html` | The whole website: layout, styling, content and editor, in one self-contained file |
| `content.json` | Created when I publish edits from the editor. If it exists, the site shows its content instead of the built-in text |

There is no build step and no server. The page runs entirely in the visitor's browser.

## Security note

This repo is public because GitHub Pages is free for public repos. It holds no passwords or tokens, only the content that is already on the website. Please don't copy my personal details, logo or text.
